# Make the Judge Laugh in One Line

One funny line, 200 characters or fewer, for the make.fun bounty
`u-email-baru-make-the-judge-laugh-in-one-line-791ccb21`.

`main.py` writes the line to `/output/entry.txt`. No input, no network,
no randomness — the same line on every run.

## Entry

> I asked the hotel for a wake-up call; at 3 a.m. they texted 'wake up' and charged it as room service.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
